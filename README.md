## Selected Projects

These projects reflect my interest in applying modern software technologies to practical financial and data problems.

### [cdm-lite](https://github.com/ben05allen/cdm-lite)

A lightweight Python library for generating Pydantic models from the FINOS Common Domain Model (CDM).

The CDM aims to provide a common representation of financial products, trades, and lifecycle events. This project explores how to make those models more accessible to Python developers without requiring a Java development environment.

### [XlyFinance](https://github.com/ben05allen/xlyfinance)

An Excel add-in built with C# and Excel-DNA, bringing historical financial market data directly into Excel.

Excel remains an essential tool in financial markets. This project explores how modern development tools can extend its capabilities without requiring users to abandon familiar workflows.
